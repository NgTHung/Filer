- [Task tracking](task-tracking.md) describes the current `.tasks` format and `taskroot` commands.
- [Task project contract](task-project-contract.md) defines the approved portable namespace and configuration behavior for UTILS-005.
- [Architecture invariants](architecture/invariants.md) lists rules enforced by Filer development tasks.
- [Filer app](architecture/filer-app.md) defines the framework-neutral architecture and evaluation contract for the desktop rewrite.
- [Comparative performance benchmarks](benchmarks/comparative-performance.md) defines peer comparisons, fixtures, metrics, and instrumented whole-pipeline journeys.
